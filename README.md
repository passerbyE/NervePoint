# NervePoint：化解規劃焦慮，專注高效執行

**我是 victo，NervePoint 的開發者。**

---

## 我的初衷：不再被「拆分任務」搞得一團亂

「把事情條列分成小項就完成一半了」——這句話我們聽得耳朵都快長繭了。但老實說，真正開始拆分一個複雜專案時，我們往往會遇到幾個狀況：

1.  **結構混亂：** 拆到一半發現彼此的關係纏繞不清，不知道哪個該先做、哪個是前提。
2.  **節外生枝：** 過程中不斷有新的問題冒出來，導致整個計畫大翻車，最後反而更焦慮、更混亂。

結果呢？我們沒有完成拆分，反而是被混亂給吞噬了。這就是**本末倒置**。

NervePoint 就是為了終結這種惡性循環而誕生的。

它給予開發者、自學者或任何需要規劃專案的人一個強大的工具：**節點關係對應圖**。

> **我的核心理念是：** 規劃不該是線性的 Do List，而是網狀的關係圖。

透過節點規劃，我們可以清楚分析「工作 A」和「工作 B」之間的真實關係。就算在思考時發現了新的障礙或分支，也能迅速透過關係連接進行修正，即時更新我們的執行清單（Do List），讓拆分任務這件事真正變得清晰、有條理。

---

## NervePoint 的核心功能：建立、詢問、產出

NervePoint 把複雜的工作流程分成了三個簡單、互補的區塊：

### 1. 建立：視覺化你的專案骨架

* **節點化事件：** 把你所有的任務和事件都變成一個個可移動、可連接的**節點**。
* **箭頭定序：** 使用**箭頭指向**來描述節點之間的依賴關係與執行順序，清楚地建立起一個邏輯嚴謹的流程圖。

### 2. 詢問：讓 AI 成為你的領域專家

* **AI 節點助手：** 當你遇到不熟悉的領域，不知道一個任務到底該如何分配步驟時（比如學習一門新外語的語法結構），可以直接向內建的 AI 助手提問。
* **對話記錄隔離：** 這是 NervePoint 很重要的一點：**AI 的對話紀錄會直接寫在那個特定的節點上**。
    * 這意味著每一件事情的輔助資訊都是獨立且專一的，不會跟其他任務的對話混雜在一起。
    * 這也讓你在實行計畫時，可以隨時回顧當初為什麼要做這個決定，或者得到哪些輔助資訊。

### 3. 產出：將圖表轉換為行動力

* **Do List 自動生成：** 一旦你的節點關係對應圖建立完成，NervePoint 就能根據圖上的邏輯順序，一鍵生成一份**清晰、具體、一步一步**的執行清單（Do List）。
* **專注執行：** 使用者只需要專注於清單上的當前任務，高效、有邏輯地推進並完成整個專案。


使用教學:
---
double-tap 空白的區域可以生成一個節點
double-tap do list 上面的內容可以標示完成，並將項目刪除與結點刪除
將滑鼠移動到節點上按下c就可以叫出chat widow 可以詢問AI助手，訊問後的結果會記錄在節點上，下次再按C就可以接著繼續詢問
