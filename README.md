專案初衷：化繁為簡，清晰導航
您是否曾聽過「把事情條列分成小項就完成一半了」這句話？雖然道理簡單，但在實際操作中，複雜的任務拆解過程往往會導致混亂、焦慮甚至產生意料之外的枝節，最終反而讓人失去方向，本末倒置。
NervePoint 的設計初衷，正是為了解決這個核心痛點。
它為開發者、專案經理或個人學習者提供了一套獨特且強大的方法論：「節點關係對應圖」。
透過視覺化的節點規劃，您能夠更有效地分析任務與任務之間的依賴關係和順序。即使在思考過程中發現了新的問題或挑戰，您也可以透過快速的關係連接，即時修改您的工作流程（Do List），確保每個步驟都清晰、邏輯連貫，最終成功將複雜任務分解為可執行的細項。

核心功能：建立、詢問、產出
NervePoint 的功能圍繞三個核心區塊運作，確保您的規劃過程完整且高效：

1. 建立 (Build)
  節點關係對應圖： 將您的各個事件或任務以視覺化的節點形式呈現。
  順序描述與連接： 使用箭頭清楚地描述事件與事件之間的執行順序和依賴關係，建立一個邏輯嚴謹的工作流程。

2. 詢問 (Query)
  內建 AI 節點助手： 當您面對不熟悉的領域，不知道如何開始或細分任務時（例如學習一門新的程式語言語法），可以立即向 AI 助手尋求指導。
  對話記錄與隔離： AI 的對話記錄會被直接儲存在對應的節點上。這確保了每個任務的輔助資訊都是獨立且方便查看的，避免了單一聊天視窗中資訊混雜的問題，同時也是計畫執行時的得力助手。

3. 產出 (Output)
  自動生成 Do List： 一旦您完成了節點關係對應圖的建立，NervePoint 就能立即依據您規劃的邏輯順序，自動生成一份清晰、一步一步的執行清單 (Do List)。
  高效執行： 使用者可以按照清單上的步驟，專注於完成當前任務，高效地推進整個專案或學習計畫。
